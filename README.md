# 랜덤 제비뽑기
Flutter/Dart 기반 랜덤 제비뽑기 앱

## 네 가지 모드

### 1. 양자택일
- 할까? 살까? 등 yes/no 질문에 반반 확률로 의견을 제시하는 기능
- 준비된 캐릭터 세트(천사/악마, 엄마/아빠 등이 등장)
- 한 번 배정된 의견은 다시 눌러도 바뀌지 않고, 새 캐릭터 세트를 고르거나 질문을 바꾸면 새로 배정.
### 2. 럭키드로우
- 경품 추첨식 럭키드로우 기능
- 뽑기에 참여하는 전체 인원 및 당첨 인원 입력 후 진행(참여 인원 2~99까지 입력 가능)
- 당첨 인원이 전부 뽑히면 종료
- 최종 화면에서 종료까지 뽑은 순서와 당첨자 번호 리스트 표시
### 3. 제비뽑기
- 뽑기 선택지 제비를 직접 작성하고 해당 제비 세트에서 뽑는 기능
- 제비 세트 슬롯 저장(최대 10개), 슬롯 당 제비 30개 저장 지원
- 제비 선택지마다 당첨 여부 설정 지원(게임 진행에 영향을 주지 않는 태그 기능)
- 모든 제비가 뽑히면 종료(언제든지 뒤로가기로 중단 가능)
- 최종 화면에서 종료까지 뽑은 제비 순서대로 리스트 표시
### 4. 커스텀 양자택일
- 양자택일 모드의 캐릭터 세트를 직접 입력하고 해당 캐릭터 풀에서 랜덤 OX 대답을 확인하는 기능
- 캐릭터 세트 입력 시 캐릭터 이름과 갤러리 이미지를 저장하고 사용 가능
- 세트 당 캐릭터 숫자는 2개 이상, 2개가 넘을 시 세트 내 2개를 무작위로 뽑아 대답 배정
- 슬라이더 형식으로 이미지 초점 설정 지원(beta)
